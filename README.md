# Interactive-Art-Generator

This **Interactive Art Generator** is a comprehensive drawing tool built with p5.js, HTML, CSS, and JavaScript. It allows users to experiment with perfect geometric shapes, a freehand pen tool, and randomized creative patterns. The generator introduces randomness to enhance creativity and provides a simple interface for users to create, modify, and save artwork.

## Features
- **Perfect Shape Drawing**: Choose from Circle, Rectangle, Triangle, or Line, and draw precise geometric shapes.
- **Freehand Drawing**: The Pen tool allows for free movement and sketching.
- **Random Mode**: Enable random mode for creative and unpredictable designs, including random colors, shapes, and sizes.
- **Customizable Stroke and Fill Colors**: Adjust colors for drawing and filling shapes.
- **Stroke Size Control**: Fine-tune the stroke size for precise drawing.
- **Clear Canvas**: Start fresh at any time.
- **Save Artwork**: Save your artwork as PNG images.

## How to Use
1. Open the app in your browser.
2. Select your tool (Pen, Line, Circle, Rectangle, Triangle), and choose colors and stroke size.
3. Enable Random Mode for creative randomness.
4. Draw on the canvas and use "Save Artwork" to download your creation.
5. Clear the canvas at any point to restart your artwork.

## Technologies Used
- **p5.js** for interactive drawing.
- **HTML/CSS** for structure and styling.
- **JavaScript** for real-time control of drawing tools and randomness.
